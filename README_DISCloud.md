# Rei Dado — Discloud

## Instalação
1. Envie o arquivo ZIP do projeto para a Discloud.
2. Configure as variáveis de ambiente no painel da aplicação.
3. Defina `DISCORD_TOKEN` com o token do bot (nunca publique esse valor).
4. Defina `GUILD_ID=1536903015678873710` e `GUILD_IDS=1558617789231661096` para sincronizar os comandos nos dois servidores.
5. Inicie a aplicação.

## Observações
- O bot foi configurado sem o módulo de apostas.
- Os jogos restantes são mantidos sem sistema de apostas.
- O banco SQLite é criado pelo próprio bot. Verifique a política de armazenamento persistente do seu plano Discloud antes de depender da persistência entre reinicializações.
- Não inclua tokens, senhas ou arquivos `.env` no ZIP.
